# Mapa de archivos

| Archivo | Responsabilidad |
| --- | --- |
| public/index.html | Pantallas, formularios y accesos |
| public/app.js | Sesión, navegación, coordinación y bloqueo durante operaciones |
| public/agenda.js / agenda-recurrente.js | Agenda, reservas, grilla habitual y asignaciones |
| public/operations.js | Caja, anticipos, lista de espera y operaciones clínicas |
| public/home.js | Inicio y accesos rápidos |
| public/ortho.js | Inventario, venta/alquiler y ficha desde Ortopedia |
| public/agenda-patient-editor.js | Editor de pacientes compartido por reserva, caja y ortopedia |
| public/patient-history.js | Ficha y cuenta clínica |
| public/coverage.js | Datos de ficha, teléfono y coberturas |
| public/api.js / config.js | Cliente y configuración pública de la conexión existente |
| public/marathon-salud.css | Tema original y alertas translúcidas de stock |
| public/agenda-recurrente.css | Grilla y botón junto a los cupos |
| public/vercel.json | Configuración estática y caché |
| supabase/migrations | Migraciones acumulativas existentes |
| supabase/functions | Funciones existentes de WhatsApp |
| tests | Pruebas simuladas de los cambios recientes |
| local | Servidor y lanzadores Windows |

Las demás hojas de estilo y módulos de public también forman parte de la aplicación; no eliminarlos por no figurar individualmente en este mapa.
