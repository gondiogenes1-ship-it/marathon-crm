# Marathon CRM — versión actual

**Versión base 0.14.0 · revisión del 04/11/2026.**

La aplicación actual está en **Ultima version del CRM**. Su ubicación se conserva para que los accesos y el servidor local sigan funcionando.

- **Ultima version del CRM/ABRIR MARATHON.cmd:** abre la aplicación real.
- **Para otras IA/Marathon_CRM_0.14.0_actual_2026-11-01.zip:** código y contexto para continuar el desarrollo en otra IA.
- **Versiones anteriores/Organizacion_20261101:** paquetes reemplazados, bocetos, demostraciones y documentación histórica. Se archivaron, no se borraron.
- **Respaldos:** copias de seguridad anteriores, conservadas.

Aplicación publicada: https://marathon-crm-liart.vercel.app/

La última publicación incluye Recibir anticipo en Inicio y Caja, creación y edición de ficha en Ortopedia, y fondos amarillos o rojos suaves según el stock. Conserva el diseño original y el botón Reservar turno junto a cupos libres.

Para otra IA, adjuntá el ZIP de Para otras IA y pedile que lea primero README.md y CONTEXTO_PARA_OTRA_IA.md. No necesita el instalador Windows ni los prototipos históricos.

El ZIP es de desarrollo, no un respaldo de la base de datos ni un instalador de Windows. Los datos reales siguen en el proyecto Supabase existente.
