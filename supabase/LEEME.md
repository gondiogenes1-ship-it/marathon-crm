# SQL y funciones del servidor

Estos archivos forman una secuencia acumulativa de cambios de Marathon; el número identifica la incorporación original, no indica que el archivo sea prescindible.

Se mantienen recuperaciones 0128, indicadores complementarios 0129, sesiones, extensión de sesiones, espacio compartido, WhatsApp, mensajes e informes de pacientes 0131, junto con las funciones del servidor en `functions`.

El proyecto compartido ya tiene los cambios aplicados. Instalar la aplicación en otra PC no requiere ejecutar estos SQL. Esta carpeta conserva los fuentes de esos cambios; no es un instalador autónomo desde cero de toda la base. Para reconstruir un proyecto distinto se necesita revisar también la estructura base y el orden de dependencias.

La limpieza del 29/10/2026 no ejecutó SQL ni modificó datos o permisos del proyecto.
